    <h1>Política de Privacidad – XZ Clipper</h1>
    <p><strong>Última actualización:</strong> 19 de octubre de 2026</p>
    
    <p>XZ Clipper es una aplicación de escritorio de uso personal que crea videos cortos (Reels) a partir de transmisiones en vivo y los publica en las páginas de Facebook que administra su propietario.</p>

    <h3>1. Qué datos usa la aplicación</h3>
    <ul>
        <li>El identificador y el nombre de las páginas de Facebook que el administrador conecta.</li>
        <li>Un token de acceso de página, necesario para publicar videos en esas páginas.</li>
        <li>Los videos, títulos, descripciones y hashtags que la propia aplicación crea.</li>
    </ul>

    <h3>2. Para qué se usan</h3>
    <p>Únicamente para publicar Reels en las páginas de Facebook del propietario de la aplicación. No se usan para publicidad, no se venden y no se comparten con terceros.</p>

    <h3>3. Dónde se guardan</h3>
    <p>Todos los datos se guardan solo en la computadora del propietario. La aplicación no tiene servidores propios ni base de datos en internet.</p>

    <h3>4. Datos de otros usuarios de Facebook</h3>
    <p>XZ Clipper no recopila, no lee y no almacena datos personales de seguidores ni de otros usuarios de Facebook.</p>

    <h3>5. Cómo eliminar los datos</h3>
    <ul>
        <li>Desde Facebook: Configuración → Seguridad e inicio de sesión → Integraciones comerciales → quitar «XZ Clipper».</li>
        <li>Desde la computadora: desinstalar XZ Clipper y elegir borrar los datos, o borrar la carpeta de datos de la aplicación.</li>
    </ul>
