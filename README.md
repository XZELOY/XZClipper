# Política de privacidad – XZ Clipper

Última actualización: 19 de octubre de 2026

XZ Clipper es una aplicación de escritorio de uso personal que crea videos cortos (Reels) a partir de transmisiones en vivo y los publica en las páginas de Facebook que administra su propietario.

## 1. Qué datos usa la aplicación
- El identificador y el nombre de las páginas de Facebook que el administrador conecta.
- Un token de acceso de página, necesario para publicar videos en esas páginas.
- Los videos, títulos, descripciones y hashtags que la propia aplicación crea.

## 2. Para qué se usan
Únicamente para publicar Reels en las páginas de Facebook del propietario de la aplicación. No se usan para publicidad, no se venden y no se comparten con terceros.

## 3. Dónde se guardan
Todos los datos se guardan solo en la computadora del propietario. La aplicación no tiene servidores propios ni base de datos en internet.

## 4. Datos de otros usuarios de Facebook
XZ Clipper no recopila, no lee y no almacena datos personales de seguidores ni de otros usuarios de Facebook.

## 5. Cómo eliminar los datos
- Desde Facebook: Configuración → Seguridad e inicio de sesión → Integraciones comerciales → quitar «XZ Clipper».
- Desde la computadora: desinstalar XZ Clipper y elegir borrar los datos, o borrar la carpeta de datos de la aplicación.
